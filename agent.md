# OBJETIVO

Crear un ecommerce de productos de tecnología con las siguientes características:

- Sistema de login básico (usuario comprador y administrador).
- Sistema de carrito de compras.
- Sistema de pago conectado con Stripe en modo test.
- Sistema de inventarios conectado con Stripe (productos, precios y activos).

# Tecnologías

- HTML

# UX/UI

- Navegación clara y sencilla.
- Página de productos.
- Página de carrito de compras.
- Página de pago.
- Página de administración de productos de Stripe.

# Avance implementado

Se generaron dos páginas HTML base:

- `login.html`: login funcional con dos usuarios de prueba.
- `productos.html`: catálogo de productos con botón "Agregar al carrito", sesión con `localStorage` y cierre de sesión.
